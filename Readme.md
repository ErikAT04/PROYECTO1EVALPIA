# Proyecto de Primera Evaluación

1. Buscar un dataset amplio, de más de 5k muestras, para analizarlo entero.
2. Realizarle un EDA completito
    - Analizar los datos y explorar las variables
    - Limpiar la información, quitar nulls, preparar strings categóricos...
    - Dejar listo el Dataset para entrenar un modelo.
3. Preparar los 4 modelos clasificatorios y un train_test_split para jugar con las predicciones.
4. Cuando tengamos los modelos, realizamos distintas predicciones cambiando hiperparámetros de cada modelo (minimo 2 cambios) y observar los resultados, comparando los scores y demás.
